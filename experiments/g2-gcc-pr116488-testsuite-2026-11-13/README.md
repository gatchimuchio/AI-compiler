# GCC 15.3.0 PR 116488 regression execution

This experiment extends the stable-source-only observation in [B57](../../docs/evidence/G2_gcc_release_followup_2026-11-13.md) with one preregistered run of the exact GCC 15.3.0 testsuite regression. Scope, source identity, build configuration, pass criteria, and stop conditions are in [preregistration.md](preregistration.md), including a pre-execution amendment to build the matching `libgcc` runtime.

Result: **16 expected passes** across eight torture-option variants. The test used the native `x86_64-pc-linux-gnu` testsuite target and exited successfully. The result record is [results.json](results.json), with the interpretation and limits in [B58 evidence](../../docs/evidence/G2_gcc_pr116488_testsuite_2026-11-13.md). Raw `.sum`, `.log`, build outputs, source archive, and toolchain captures are preserved outside the repository at `/tmp/aic-gcc15-pr116488-2026-11-13/`. The actual archive came from GCC's official `gcc.gnu.org` release directory rather than the preregistered `ftp.gnu.org` URL; this deviation and checksum match are recorded in the results.
