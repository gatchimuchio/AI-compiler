## Result

The unmodified GCC 15.3.0 C frontend passed its own `gcc/testsuite/gcc.dg/torture/pr116488.c` regression on the executor's native Linux x86-64 target. DejaGnu reported **16 expected passes**: eight torture-option variants, each with one excess-diagnostics check and one executable run. There were no `FAIL`, `XPASS`, `XFAIL`, `UNSUPPORTED`, `UNRESOLVED`, or `UNTESTED` statuses for the selected tests. `make check-gcc` exited 0; the selected testcase completed in one second.

The eight variants were `-O0`, `-O1`, `-O2`, `-O3 -fomit-frame-pointer -funroll-loops -fpeel-loops -ftracer -finline-functions`, `-O3 -g`, `-Os`, `-O2 -flto -fno-use-linker-plugin -flto-partition=none`, and `-O2 -flto -fuse-linker-plugin -fno-fat-lto-objects`. The release testcase supplies `-fno-forward-propagate` and checks the `dg-do run` result.
